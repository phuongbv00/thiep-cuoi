# Ảnh cưới

Chép ảnh vào thư mục này với đúng tên dưới đây (định dạng .jpg). Ảnh nào chưa có sẽ tự hiện khung placeholder.

| Tên file | Dùng cho | Gợi ý |
|---|---|---|
| `cover.jpg` | Ảnh bìa | Ảnh dọc, ~1080×1600 |
| `portrait.jpg` | Ảnh đôi trong khung vòm (mục Cô dâu & Chú rể) | Ảnh dọc 3:4, hai người đứng cạnh nhau |
| `couple.jpg` | Ảnh đôi ở phần lời mời | Ảnh ngang 4:3 |
| `footer.jpg` | Ảnh kết thiệp | Ảnh dọc/ngang đều được |
| `album-01.jpg` … `album-09.jpg` | Album | Ảnh 01 và 06 hiển thị lớn |

Nên nén ảnh (rộng ~1200–1600px, < 500KB/ảnh) để thiệp mở nhanh trên điện thoại.
